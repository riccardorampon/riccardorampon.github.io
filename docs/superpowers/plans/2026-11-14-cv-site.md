# CV Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-page static CV site for `riccardorampon.github.io`: fixed dark sidebar with identity, section nav and contact links; scrolling content with About, Experience, Projects, Skills, Education, Languages & hobbies.

**Architecture:** Three files at the repo root: `index.html` (all content, semantic markup), `style.css` (layout B, responsive under 800px), `cv.pdf` (redacted CV supplied by Riccardo). GitHub Pages serves the repo root of `main` as-is. No JavaScript, no build.

**Tech Stack:** HTML5, CSS (grid, `position: sticky`, one media query). Checks use `grep`, `git`, `pdftotext`, and Firefox (all already installed).

**Spec:** `docs/superpowers/specs/2026-11-14-cv-site-design.md`

## Global Constraints

- Phone number and date of birth appear nowhere on the site or in the repo — including this plan, commit messages, and `cv.pdf`.
- `docs/Developer_Resume.pdf` is never committed (already in `.gitignore`; keep it there).
- Public repo: anything committed is public.
- Files: `index.html`, `style.css`, `cv.pdf` at repo root. No JavaScript, no dependencies, no build step, no web fonts.
- English only.
- Section order: About → Experience → Projects → Skills → Education → Languages & hobbies.
- Sidebar: name, "AI/ML Engineer", "Padua, IT", nav (About, Experience, Projects, Skills, Education), links GitHub · LinkedIn · Email (`mailto:`) · CV ↓.
- Breakpoint: under 800px the sidebar becomes a top header and sections stack.
- Work happens on branch `develop`; Pages publishes from `main` (merge is the finishing step, not a task).

**Privacy check command** (used in Tasks 1–3; the bracketed characters stop the pattern from matching itself):

```bash
git ls-files --cached --others --exclude-standard -z | xargs -0 grep -nE '\+3[9]|19[9]9|Januar[y]'
```

Expected: no output (xargs exits 123 because grep found nothing).

## Review Focus

1. **320px-wide phone:** no horizontal page scroll — long tokens (email address, "CloudFormation", "Model Context Protocol") wrap. → Task 2, Step 4.
2. **Short desktop window (1280×600):** the sticky sidebar's own content scrolls rather than being cut off. → Task 2, Step 4.
3. **Keyboard-only visitor:** first Tab shows a "Skip to content" link; every link has a visible focus ring on both the dark sidebar and the light content. → Task 2, Step 4.
4. **Anchor navigation:** clicking a nav link lands with the section heading visible, on desktop and on mobile. → Task 2, Step 4.
5. **Wrong `cv.pdf`:** an unredacted export (text, link annotations, or metadata carrying phone/DOB) gets committed. → Task 3, Step 2.

- [ ] **Step 1: Write the CSS check** (scratch command)

```bash
f=style.css; ok=1
grep -q '@media (max-width: 799px)' $f || { echo "no breakpoint"; ok=0; }
grep -q 'position: sticky' $f || { echo "sidebar not sticky"; ok=0; }
grep -q ':focus-visible' $f || { echo "no focus style"; ok=0; }
grep -q 'overflow-wrap: anywhere' $f || { echo "no long-word wrap"; ok=0; }
grep -q 'scroll-margin-top' $f || { echo "no anchor offset"; ok=0; }
grep -qE '@import|url\(https?:' $f && { echo "external resource"; ok=0; }
[ $ok = 1 ] && echo CSS OK
```

- [ ] **Step 2: Run it to verify it fails**

Expected: `grep: style.css: No such file or directory`, no `CSS OK`.

- [ ] **Step 3: Write `style.css`**

- ≥800px: `body` is a grid `16rem 1fr`; `header.sidebar` is `position: sticky; top: 0; height: 100vh; overflow-y: auto` with the dark tokens; `main` scrolls with the page.
- `@media (max-width: 799px)`: single column; sidebar is a static full-width top header (`position: static; height: auto`), nav and contact lists wrap horizontally.
- `.skip-link` off-screen until `:focus`.
- `:focus-visible` → `outline: 2px solid` accent (sidebar variant uses `#93c5fd`), `outline-offset: 2px`.
- `section { scroll-margin-top: 1rem; }` (sidebar is not sticky on mobile, so no larger offset needed).
- `main { overflow-wrap: anywhere; }` and the same on `.contact`.
- `.tags` inline-flex wrap chips; `.cards` grid `repeat(auto-fill, minmax(16rem, 1fr))`; `.card` bordered block.
